# Student Manager (C++)

A simple console-based student management system built in C++.
It lets you add, view, search, delete, and calculate the average
grade of students using a menu-driven interface.

## Features

- ➕ Add a student (name, age, grade)
- 📋 View all students
- 🔍 Search for a student by name
- 🗑️ Delete a student by name
- 📊 Calculate the average grade of all students
